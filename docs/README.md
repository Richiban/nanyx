# Nanyx docs

The documentation site for Nanyx, built with [Astro](https://astro.build) and
deployed to Vercel as static HTML.

## Working on the site

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
npm run preview  # serve dist/ locally
npm run check    # type-check .astro and .ts files
```

## Where things live

- `src/content/<section>/*.md` — the documentation pages. Each file has
  `title`, `description` and `order` front matter. `#` headings inside a page
  are rendered as `h2` (the title is the `h1`).
- `site/sections.mjs` — the ordered list of sections, their directories and
  sidebar icons. Add a section here and create the matching content directory.
- `site/shiki-themes.mjs` — the light and dark code themes. The Nanyx grammar
  comes from `../extension/syntaxes/nanyx.tmLanguage.json`, the same file the
  VS Code extension ships.
- `site/rehype-plugins.mjs` — heading level shift and heading anchor links.
- `src/pages/docs/[...slug].astro` — the doc page template.
- `src/components/` — layout pieces. `SearchDialog.tsx` is the only React
  island; everything else is static HTML with small inline scripts.
- `src/styles/global.css` — Tailwind setup and site styles.

## Machine-readable output

- `/llms.txt` — index of every page with descriptions.
- `/llms-full.txt` — the whole documentation set as one markdown file.
- `/docs/<section>/<page>.md` — any page as plain markdown.
- `/sitemap-index.xml` — generated by `@astrojs/sitemap`.
